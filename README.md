# Lucky68 Gallery

A bilingual English / Chinese archive of 120 ImgBB albums and 1,169 photos. Albums are grouped and sorted by brand, with search, brand filtering, photo counts, and direct source links.

## View

Open `index.html` in a browser, or visit [Lucky68 on GitHub Pages](https://wh0isrh.github.io/lucky68-gallery/).

Photos are served by ImgBB and require an internet connection. Album titles preserve the original Chinese source title when the interface is set to English.

## Design

The page is a static, dependency-free catalogue: a compact editorial intro, brand navigation and logo headers, uncropped album covers, and expandable photo grids. It adapts useful image-card and motion patterns from the separate website-cloner project while keeping GitHub Pages delivery simple. The user-approved design record is in `docs/superpowers/specs/2026-11-10-lucky68-catalogue-redesign-design.md`.

## Brand marks

Logo SVGs are stored locally so brand headers render reliably on GitHub Pages. Sources: [Moncler](https://companieslogo.com/moncler/logo), [Ralph Lauren](https://commons.wikimedia.org/wiki/File:Ralph_Lauren_logo.svg), [Stone Island](https://commons.wikimedia.org/wiki/File:Stone-Island-Logo.svg), and [The North Face](https://commons.wikimedia.org/wiki/File:TheNorthFace_logo.svg).
